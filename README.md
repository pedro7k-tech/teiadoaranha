# 🕸️ Landing Page de Alta Conversão — Lançador de Teias Infantil

Landing page de alta conversão criada especialmente para tráfego pago (Instagram, TikTok, Facebook Ads e Google Ads), focada na venda do **Lançador de Teias Infantil com Bateria Recarregável e Rebobinamento Automático**.

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Node.js instalado (v18+)
- Gerenciador de pacotes `npm` ou `yarn`

### Passo a passo
1. **Instalar dependências:**
   ```bash
   npm install
   ```

2. **Rodar em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse no navegador: `http://localhost:3000`

3. **Gerar build de produção:**
   ```bash
   npm run build
   ```
   Os arquivos otimizados e minificados serão gerados na pasta `dist/`.

4. **Visualizar o build gerado:**
   ```bash
   npm run preview
   ```
